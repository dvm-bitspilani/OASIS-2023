# Oasis 2023 portfolio restoration

Starting commit: `811ea92a40c6fd3baa8ab49005cc37bc43976e40` (main).

The approved restoration retains the original illustrated pages, artwork, carousels, GSAP transitions and routes. Persistent archive wording identifies this as a portfolio archive. Thirteen event descriptions and their artwork are grounded in `src/helpers/Events.js`. Sponsors, media, wall magazine and college records are explicitly representative demos because their original API records are unavailable. Registration validates required fields, email and ten-digit phone input locally and confirms in memory; it does not send, persist or register information. Analytics and CAPTCHA were removed.

Next 16.3.8 and React 19.3.0 produce a static `out` export. Images are preprocessed and unoptimized Next Image rendering needs no server. Vulnerable PDF libraries and remote worker were replaced with lazy native PDF frames and direct original PDF links inside the original carousel shell. Home and registration no longer wait for artwork or fixed loading delays. Major home views load through dynamic chunks; YouTube frames are lazy.

Large SVG embedded rasters were recompressed to WebP while retaining SVG geometry; large raster illustrations and portraits use WebP. Optimized asset set: 125,513,263 → 22,725,013 bytes (public and imported developer assets combined). Font files: 8,176,176 → 428,300 bytes. Original local font families are retained, subset with Latin, extended Latin and punctuation coverage, served as WOFF2 with swap; Montserrat preserves variable weight coverage. Misspelled KoPub Batang and OldNewsPaper family references were corrected. Source font/asset records are in `evidence/fonts.json` and `evidence/assets.json`. Public directory falls from about 108MB to 42MB. Original source artwork remains recoverable in Git history.

Wrangler 4.145.0 is pinned. Deploy script targets `dvm-portfolio-oasis-2023` with account ID provided as an environment variable (Pages configuration does not support account_id). Canonical and social metadata use https://oasis2023.bits-oasis.org. No Worker or backend is needed. Next inline bootstraps are extracted into same-origin scripts after export. CSP has no unsafe-eval or inline script permission and each generated header line is below the Cloudflare 2KB cap; inline styles remain allowed for original animation/style behavior. Native PDF files remain same-origin. YouTube frames are the only permitted external embeds.

Verification: reproducible `npm ci --legacy-peer-deps`; production `npm run build` (11 original routes plus static error pages); `npm run check` (exported routes/archive wording, external bootstrap, header cap and CSP, local fonts); `npm audit` for all production and development dependencies reports zero vulnerabilities. Evidence logs are checked in under `evidence/`. Source review found no remaining fetch/API calls, unsafe HTML injection, credential handling or browser storage. No deployment or remote Git operations were performed by the restoration agent. Root agent handles browser interaction review and publishing. Mobile/performance testing was explicitly waived by the user.

Limitations: archived contact/social links retain historical public destinations; third-party video availability and native browser PDF support are outside the archive's control. Demo partner records do not assert historical sponsorship. Registration is closed and its confirmation is demonstration only.
